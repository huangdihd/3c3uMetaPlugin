> A specialized MetaPlugin for **3c3u.org**, built on the [xinbot](https://github.com/huangdihd/xinbot) framework.

English / [简体中文](README_zh.md)

---

## Features
- **Automated Authentication**: Seamlessly handles the login and verification flow for 3c3u.org.
- **Queue Intelligence**:
    - Real-time queue position tracking.
- **Multi-language Support**: Built-in support for EN, DE, FR, JP, RU, and ZH.

---

## Quick Start

1) Download
   Obtain the latest `3c3uMetaPlugin.jar` from the [Releases](https://github.com/huangdihd/3c3uMetaPlugin/releases) page.

2) Install
   Place the JAR file into the `plugin` directory of your xinbot installation. Java 17 or newer is required.

3) Run
   Start xinbot. The plugin will be loaded automatically to handle the 3c3u.org protocol specifics.
